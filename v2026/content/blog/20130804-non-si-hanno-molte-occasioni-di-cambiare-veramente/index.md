# Non si hanno molte occasioni di cambiare

<blockquote>
  <p>Non si hanno molte occasioni di cambiare veramente le cose, per questo vanno assolutamente colte. Comunque vada si sarà predisposta una strada per l’occasione successiva.</p>

</blockquote>
